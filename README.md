# 铁林健身品牌官网

## 项目简介
为成都高新区“铁林健身”搭建的品牌展示官网。客户为24小时社区健身房，拥有3家门店，通过官网展示品牌形象、门店信息、企业团课及加盟合作服务，提升品牌专业度并获取企业客户线索。

## 项目信息
- **客户**：铁林健身（成都高新区，3家门店）
- **类型**：网站 · 无后端
- **价格**：¥1,680
- **交付周期**：2-3天
- **技术栈**：HTML/CSS/JS（纯静态）

## 页面结构
- **首屏**：品牌slogan与氛围大图
- **关于我们**：3个核心卖点卡片（24小时营业、社区型场馆、专业教练）
- **门店信息**：3家门店卡片（地址、面积、特色）
- **企业服务**：企业团课定制与品牌加盟合作
- **常见问题**：手风琴折叠面板（5个FAQ）
- **联系表单**：咨询类型可选个人健身/企业团课/加盟合作

## 功能特点
- 手机/电脑自适应，移动端优先设计
- FAQ手风琴折叠，纯JS实现
- 配色硬朗活力（深墨绿+活力橙），契合健身品牌调性
- 纯静态页面，零服务器成本，部署于 Cloudflare Pages

## 部署方式
本项目部署于 Cloudflare Pages，更新代码后自动同步上线。
